# Discovery and implementation decisions

The initial workspace contained only Images/ and Git metadata: no application, routes, dependency manifest, or existing build to run. All 143 image files were recursively decoded, dimensioned, byte-hashed, and visually reviewed in a contact sheet. docs/asset-inventory.json records every source and decision. Twenty distinct photographic/branding subjects are represented; other crops/resolutions are deliberately consolidated. Saved map tiles, map marker and transparent browser artifacts are not displayable photography.

Business source: https://tarlac-marcimetzger-homeproject.vercel.app/ and its delivered /assets/index-C3YXNJcI.js, retrieved 2026-10-26. Confirmed Marci Metzger, The Ridge Realty Group, career starting 1995, Washington State broker background, 3190 HW-160 Suite F Pahrump Nevada 89048, (206) 919-6886, office hours 8am–7pm daily, and social routes. No verified property records or associations exist. Image subjects are descriptive, not listing names. No fabricated price, location, availability or room counts. The original search handler only prevents submission, its navigation links point to #, and no inquiry delivery endpoint was found. Replace these dead ends with working section navigation, image-detail pages, and verified telephone/social contact routes. A real listings feed/form endpoint is required to add those services.

Reference: https://veryonlinestudio.com/demos/photo/ markup retrieved. Observed in source: expansive photographic hero, editorial type, introductory statement, contact sheet, sticky focus interlude, light/photography chapters, motion-skip controls and responsive picture sources. Visual/browser observations are reported separately; source reading is not proof of animation feel. No proprietary reference images or branding copied.

Implementation: static Astro pages and optimized image imports; React only for the official Circular Carousel; one Lenis controller; native dialog gallery; IntersectionObserver reveals; perspective doors with session storage, skip and reduced-motion bypass. Navigation preserves original meaningful section anchors with aliases. Static dist output is Vercel compatible.

React Bits: https://reactbits.dev/components/circular-carousel documents shadcn registry installation (CircularCarousel-TS-TW). We vendor the official TypeScript/plain-CSS variant directly from https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/CircularCarousel with upstream license retained. Source has only React/CSS imports, built-in keyboard, pointer momentum/snap, resize and visibility observers, reduced-motion handling. Adaptations: remove unused stock sample data; expose named previous/next controls; reduced-motion/static no-JS fallback supplied outside the ring. No generic slider substitution.

Browser follow-up: desktop and mobile reference screenshots were successfully captured, including scrolled states. Visually observed the large serif name overlay on landscape photography, viewfinder-style frame, light editorial sections and a mobile lens interlude. The final website translates these compositional principles into architectural imagery and paneled doors rather than reusing the reference's camera motifs.
